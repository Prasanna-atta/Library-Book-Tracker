
# Library Book Tracker

## Description
A simple web application for managing library books.

## Features
- Add book names and author names.
- Display available books.
- Delete books from the list.
- Responsive and simple interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Files
- index.html
- style.css
- README.md

## Purpose
This project demonstrates basic web development and Git/GitHub version control.
